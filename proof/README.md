# Proof of Execution

## Visual States Confirmed
This directory contains proof that the 3 main states (Marketing, Course Portal, and Blog) of the Germaine Tutoring layout function successfully.

The tests capture screenshots across two viewports (1280px for desktop and 375px for mobile), reflecting responsive design.

| Screenshot Path | State / Feature Proven | Viewport |
| :--- | :--- | :--- |
| `proof/1280/marketing.png` | Marketing layout rendered correctly | 1280px |
| `proof/375/marketing.png` | Marketing layout responsive wrapping | 375px |
| `proof/1280/course-portal.png` | Course Portal layout rendered correctly | 1280px |
| `proof/375/course-portal.png` | Course Portal layout responsive wrapping | 375px |
| `proof/1280/blog.png` | Blog campaign layout rendered correctly | 1280px |
| `proof/375/blog.png` | Blog campaign layout responsive wrapping | 375px |

## Walkthrough
Since a direct video recording was unavailable inside the headless execution environment, a sequence of frame snapshots (`proof/walkthrough/001.png`, etc.) was captured to prove the live interaction (clicking through the tabs and loading the dynamic panel states).
